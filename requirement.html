① Overview

โปรเจค "Off Mai" (ออฟใหม่) — ระบบผู้ช่วยแทนทีม Tech Support ในบริษัท รับแจ้งปัญหา/คำถามจากลูกค้าทาง LINE วิเคราะห์ด้วย API AI CENTER จัดเก็บลง database ส่งต่อให้ทีม Tech Support ทาง MS Teams และวนกลับมาวิเคราะห์คำตอบของทีม ก่อนส่งกลับลูกค้า — ในระยะยาวจะสะสมข้อมูลเพื่อแนะนำวิธีแก้แบบมีความมั่นใจ (confidence) และพิจารณา auto-answer ในอนาคต โหมดของ requirement นี้คือ Greenfield (front/back ยังเป็นแค่ README ยังไม่ได้พัฒนาจริง) จึงออกแบบ mockup จากสเปกที่เขียนไว้ ทุกหน้าจอถูกแท็ก Planned

② Workflows

4 workflow หลัก ตั้งแต่รับแจ้งปัญหาจนถึงการเรียนรู้และ automation ในอนาคต

WF-001 รับแจ้งปัญหาทาง LINE & วิเคราะห์โดย AI CENTER

WF-001→ UC-001 UC-002 UC-003

ลูกค้าส่งข้อความ/แจ้งปัญหาผ่าน LINE → ระบบเรียก API AI CENTER วิเคราะห์ข้อความ → บันทึกเคส (ลูกค้าคนไหน + ข้อความต้นฉบับ + ข้อความที่วิเคราะห์แล้ว) ลง database ทั้งหมด ก่อนส่งต่อไปยัง WF-002

WF-002 ส่งต่อทีม Tech Support ทาง MS Teams & วิเคราะห์คำตอบ

WF-002→ UC-004 UC-005 UC-006 UC-007

ระบบส่งข้อความลูกค้า + ข้อความต้นฉบับ + ผลวิเคราะห์ ให้ทีม Tech Support ใน MS Teams เมื่อทีมแก้ไข/ตอบกลับแล้ว ระบบต้อง วิเคราะห์ข้อความตอบกลับก่อน เพื่อสกัด "วิธีการแก้ปัญหา" ของเคสนั้น ๆ แล้วจึงเก็บลง database

WF-003 ส่งคำตอบกลับลูกค้าทาง LINE

WF-003→ UC-008 UC-009

นำข้อความของทีม Tech Support ไปส่งลูกค้าที่ LINE โดยระบบอาจช่วยปรับ/แก้ข้อความของทีมให้เข้าใจง่ายขึ้นก่อนส่งถึงลูกค้า

WF-004 การเรียนรู้เคส & แนะนำวิธีแก้ตามความมั่นใจ Planned — future phase

WF-004→ UC-010 UC-011 UC-012 UC-013 UC-014

เมื่อข้อมูลเคสเติบโตมากพอ (เคสที่เกิดบ่อย ประเภท หมวดหมู่ ความมั่นใจ วิธีแก้ของแต่ละเคส) ระบบจะวิเคราะห์เคสใหม่เทียบกับ ประวัติก่อนแจ้งเข้ามา หากมั่นใจ 90-100% จะถามทีม Tech Support ให้ยืนยันก่อน หากยืนยันซ้ำจนมั่นใจ 100% จะเก็บไว้เป็นรายการ ที่ต้องคุยกับทีมต่อว่าจะเปิดใช้ API / automate / auto-answer LINE หรือไม่
